# 英语小探险 English Adventure

给小学低年级孩子的英语入门练习，单个网页，打开就能用。

- **每日任务**：每天自动生成 3–5 个任务（学新词、字母闯关、错题复习、听力挑战、线下小任务），可以换一批
- **打卡**：任务全部完成后打卡，生成打卡卡片；打卡日历、连续天数和徽章
- **12 个主题**：字母、打招呼、数字、颜色、动物、水果食物、身体、家人、学校、玩具交通、天气自然、动作
- **题型**：看图选词、读词选图、听音选图、中英互选、补字母、字母大小写 / 听字母 / 字母顺序 / 首字母
- 新词卡片、错题本、星级、提示 / 挑战模式、英音 / 美音、语速调节

学习记录保存在浏览器本地（localStorage），换设备或清除浏览器数据会重新开始。
